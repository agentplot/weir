# Proposal

## Why

On 2026-11-12 every repository weir's tree names moved from the
agentplot owner on GitHub to boomdrivedev, agentplot/boomdrive-web and
the archived agentplot/flywheel alone staying. The brief of the fix
main--weirs-addresses-name-boomdrivedev asks: "Every agentplot/ address
in weir's tree of a tool that has moved names boomdrivedev/ instead".
Two specs cite a moved address in a requirement: conformance-pack's
index names the statement in agentplot/blueprints, and remote-limit's
limit names agentplot/sluice's record 0109. A spec changes only through
a change, so this one carries both (record 0009).

## What Changes

- conformance-pack's *The pack keeps an index of the statement's
  clauses* names the statement in boomdrivedev/blueprints, at the same
  commit, 006fc34; the pack's index names its statement
  `boomdrivedev/blueprints:design/weir/requirements.md`.
- remote-limit's *The limit and the grace are the family's* names
  boomdrivedev/sluice record 0109.
- Beside them, as record 0009 says: the README, CLAUDE.md, the OpenSpec
  config, the comments of `Cargo.toml`, `devenv.nix`, `.gitignore` and
  `.vale.ini`, the Vale rules' links, the rules' narrative and core.53's
  sources, the crates' module comments, the records' citations, and the
  fixtures that name weir's own repository name boomdrivedev.
- weir-branch's, weir-signals' and weir-cadence's names tests read a name
  core.2 rules out as a whole word, as weir-pack's, weir-adapters',
  weir-bounded's and the command's already do, so `boomdrivedev`, an
  owner, reads as no tool.
- No behavior, clause or rule changes. Names that are no address, the
  family's name in prose, the kit standard's org, the license's holder
  and the streams `agentplot-design` and `agentplot-ops`, stay, as do
  the archived changes.
